# Tampermonkey-YouTube-Zoomify
A simple tool which allows you to zoom in and out inside YouTube videos, while maintaining regular functionality.
This script doesn't require any external scripts or libraries, the code you see is the code you get, everything is done locally within _your_ browser.

## Installation
Simply install one of the following: Greasemonkey [[ff][FF Greasemonkey]], Violentmonkey [[ff][FF Violentmonkey]][[ch][Ch Violentmonkey]], Tampermonkey [[ff][FF Tampermonkey]][[ch][Ch Tampermonkey]]  
Click this link: [YouTube Zoomify.user.js](https://github.com/Skyknight47/Tampermonkey-YouTube-Zoomify/releases/download/v1.0.5/YouTube.Zoomify.user.js)  
Your chosen add-on should then provide you with an install option, simply follow the instructions.

## Usage
Once installed, head over to YouTube, open up a video, and move your Mouse cursor the location you want to zoom in on. Now you're ready!
Simply hold down your (Left) _SHIFT_ button, while using your Mouse _SCROLLWHEEL_ to zoom in/out on the position of your Mouse cursor.

This script is very lightweight and should have a minimal performance impact, if any.  

If you encounter any issues whilst using this script, please [let me know](https://github.com/Skyknight47/Tampermonkey-YouTube-Zoomify/issues).  
While I'm not actively maintaining this repository, I will fix critical bugs every now and then. You're welcome to fork this repository and create your own version.

## Limitations
Due to the nature of YouTube, YouTube's `<video>` element can be affected by its own CSS/layout when zoomed, particularly when using theatre mode. This may cause unexpected behaviour!
